    OnionClaw gives an agent the whole dark-web OSINT toolkit. Scroll to peel the onion, one encryption layer at a time.

    01 Layer one · Guard

    Search seventeen engines at once.

    search.py sends one query to 17 .onion search engines in parallel. The results come back merged, deduplicated and ranked by relevance.

    Ahmia · OnionLand · Amnesia · Torland · Excavator · Onionway · Tor66 · OSS · Torgol · TheDeepSearches · Kaizer · Anima · Tornado · FindTor · Torgle · DuckDuckGo-Tor · Ahmia-clearnet

    02 Layer two · Middle

    Read any hidden service.

    fetch.py loads any .onion or clearnet page through Tor and returns clean text, links and extracted entities. renew.py asks Tor for a new circuit, so the next request leaves from a different exit relay.

    03 Layer three · Exit

    From raw pages to a report.

    pipeline.py runs a whole investigation in one command: refine the query, search, filter, scrape the top hits, then write an analyst report. It has four modes (threat intel, ransomware, corporate and identity exposure) and works with ten LLM providers, including local Ollama.

    04 The core · v2.4

    A swarm that watches while you don't.

    Five read-only collectors run in parallel and store what they see in SQLite. Each sweep reports only what changed: new leak-site victims, infrastructure going up or down, exploited CVEs newly tied to ransomware, and movement on tracked wallets.

    leaksites · groupinfra · kev · wallets · onionsites

    05 Signal

    Evidence, not guesses.

    Groups are linked only through hard evidence such as a shared wallet, a shared leak-site host or the same alias, and every link shows its proof. Findings export as STIX 2.1, validated against the OASIS reference library, and go out as signed webhooks, delivered exactly once. 71 tests run on real captured data.

    06 Get started

    Point an agent at the dark web.

    The only setup is a .env file. Install it as an OpenClaw skill, or run any command from a terminal.

    cp -r OnionClaw ~/.openclaw/skills/onionclaw
