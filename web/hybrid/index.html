      Open source · OpenClaw skill · built on SICRY™

      Full Tor access
      for AI agents.

      The onion is a planet now. Scroll to orbit it station by station, then explore it yourself.

      01 Radar station · search.py

      Seventeen engines, one query.

      Every moon in orbit is a search engine. One search goes to all 17 in parallel, and the results come back merged, deduplicated and ranked by relevance.

      02 Tower · fetch.py

      Read any hidden service.

      Load any .onion or clearnet page through Tor and get clean text, links and extracted entities back.

      03 Windmill · renew.py

      A fresh circuit on demand.

      Ask Tor for a new circuit, so the next request leaves from a different exit relay.

      04 Lighthouse · pipeline.py

      From raw pages to a report.

      One command refines the query, searches, filters, scrapes the top hits and writes an analyst report. Four modes, ten LLM providers, including local Ollama.

      05 The core · swarm.py · v2.4

      A swarm that watches for you.

      Peel the planet open and the monitoring swarm is at its heart. Five read-only collectors run in parallel and report only what changed since the last sweep.

      leaksites · groupinfra · kev · wallets · onionsites

      06 Signal · stix.py

      Evidence, not guesses.

      Groups are linked only through hard evidence such as a shared wallet, host or alias, and every link shows its proof. Findings export as validated STIX 2.1 and go out as signed webhooks, delivered exactly once.

      Point an agent at the dark web.
